Создайте здесь 001_schema.sql со своей предметной схемой app. В исходной поставке предметных миграций нет. Нумерация: 001_schema.sql, 002_resource_note.sql и далее. Используйте только строчные латинские буквы, цифры и подчёркивания.

Миграции выполняются от lab_owner. Уже применённый файл не изменяйте; добавляйте новый. Runner рассчитан на один запускающий процесс.
